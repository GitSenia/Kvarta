# README

## ИИ

- Лендинг: вёрстка, тексты, анимации, OG.
- Каркас FastAPI: `POST /api/lead`, валидация BY-телефона, дедуп, UTM.
- Черновик Docker Compose и правки по фидбеку.

## Самостоятельно

- Выбор стека (FastAPI + Docker + Postgres вместо Next/Vercel).
- Таблица `telegram_manager`, пару Pydantic-схем, функции записи/чтения менеджеров, дубль заявок в Telegram, polling `/start`.
- Аренда VPS (cloudvps.by), SSH-ключ, фаервол (`ufw`: 22/80/443), установка Docker.
- Деплой на сервер: залил проект, `.env`, `docker compose` — сайт: http://45.129.186.230/
- Ревью кода и логов, дизайн-правки, токен бота, пуш в GitHub.

## Где ИИ ошибся

- Telegram сначала без вызова из API — заявки в бот не шли, дописал сам.
- Сборка Docker падала на aiogram/aiohttp — видно в логе `compose build`.
- UX (доставка, цвет текста в форме) — по скринам, не по «зелёному» билду.

- Lighthouse mobile — после привязки домена.
